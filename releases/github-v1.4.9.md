# XenAddons v1.4.9

Minecraft `26.1.2` • Fabric • Java `25+`

## Added

- **New Category: FISHING**

- **Fishing Hook Display** (FISHING)
  - HUD showing the Hypixel fishing timer (bold, pale yellow) and the pull alert once your hook is ready to be reeled in.
  - The alert text is editable ("Custom Alert Text", `!!!` by default) and always renders bold red, whatever you type in it.
  - Automatically hides the vanilla Hypixel nametag floating above your bobber while the module is on, so you don't see the timer twice.
  - Position and scale are draggable from the HUD editor (`/xa hud`).

- **Hotspot Highlight** (FISHING)
  - Highlights fishing hotspots (Sea Creature, Fishing Speed, Double Hook, Treasure, Trophy Fish, Shard Chance) with a color matching their buff type.
  - Renders an outline and/or a filled surface circle at the water's surface, each with its own opacity slider.
  - Hides the hotspot's spawn particles automatically while the module is on.

- **Hide Other Bobbers** (FISHING)
  - Hides every other player's fishing bobber, so only yours is ever visible.

- **Highlight Pressure Plate** (DUNGEONS)
  - Highlights the Light Weighted Pressure Plate at the I4 room's fixed spot in green, only while it's actually pressed.
  - Only active while in a dungeon.

## Notes

- All four new modules are off by default, like every other module.
