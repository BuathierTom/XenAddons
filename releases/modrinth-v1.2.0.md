# XenAddons 1.2.0

**Minecraft 1.21.10 (Fabric)**

## Changes

- Added resource-based visual configuration:
  - `assets/xenaddons/visual/visualWords.json`
  - `assets/xenaddons/visual/customSizes.json`
- Added capybara bitmap font support for Visual Words:
  - `assets/xenaddons/font/capybara.json`
  - `Antorak` now supports a `{capy}` icon token
- Removed non-working butt-boost experimental renderer
- Kept stable `Custom Size` per-UUID scaling
