# XenAddons v1.4.10

Minecraft `26.1.2` • Fabric • Java `25+`

## Changed

- **Update Checker**
  - No longer downloads the update automatically. It now shows a chat reminder with a clickable link to the Modrinth page when a newer version is available, so you choose when to update.

- **Custom Names (Cosmetics)**
  - A custom name can now be animated: several color frames smoothly blended into each other, instead of a single static color per letter.
  - Shows up wherever custom names already did — above a player's head and in the tab list.
