# XenAddons v1.4.4

Minecraft `26.1.2` • Fabric • Java `25+`

## Added

- **Hide Parts on Rod**
  - Hides the empty `Hook`, `Line` and `Sinker` lines from fishing rod tooltips, along with the line pointing to Roddy in the Backwater Bayou.
  - Rods with parts fitted are left untouched, their descriptions included. Rods with only some slots filled keep the fitted ones and lose the empty ones.
  - Includes an optional keybind to toggle it without opening the menu. Unbound by default.
