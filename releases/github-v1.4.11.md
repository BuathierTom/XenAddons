# XenAddons v1.4.11

Minecraft `26.1.2` • Fabric • Java `25+`

## Changed

- **Show Ultimate Enchant**
  - Now also marks a Hyperion carrying Chimera, Swarm, Ultimate Wise, Combo, Soul Eater, Fatal Tempo, or Inferno, with its own toggle next to the existing Terminator one.
  - The label color is now a color picker instead of a fixed color, defaulting to the previous pink.
  - The label sits 1px off the slot's edge and is drawn slightly smaller.
