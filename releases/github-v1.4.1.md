# XenAddons v1.4.1

Minecraft `26.1.2` • Fabric • Java `25+`

## Added

- **Show Ultimate Enchant**
  - Show on Terminator with Soul Eater or Duplex with a `SE` or `DU` label on its item slot.

- **Spotify Overlay**
  - Added an option that hides the Better Display overlay while nothing is playing.

- **Command Aliases**
  - Added `/ca`, `/cp`, `/cg`, and `/cc` for `/chat all`, `/chat party`, `/chat guild`, and `/chat coop`.

## Changed

- **Inventory Buttons**
  - Rebuilt the menu, the configuration screen, and the button editor.

## Fixed

- **Item Price**
  - Shards now show their Bazaar price, resolved from the item name since they carry no SkyBlock ID.

- **Inventory Buttons**
  - Icon tooltips in the editor were never displayed and now work.
