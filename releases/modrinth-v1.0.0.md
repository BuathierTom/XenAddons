# XenAddons 1.0.0

**Minecraft 1.21.10 (Fabric)**

Release complète avec modules Dungeon/Misc/Dev, HUD editor, et Players Leaped.

## Ajouts / changements

- Ajout: **Players Leaped** (Dungeon HUD)
- Suppression: **Melody Warning**
- HUD editor fonctionnel pour éléments supportés (move/scale/reset)
- SecretRoutes configurable (couleur, alpha, épaisseur, toggles de rendu)

## Modules inclus

### Dungeon
- **Auto Pet Rule Title**
  - Notification HUD AutoPet
- **Pos Message**
  - Callouts auto en party chat
- **Pos Titles**
  - Callouts HUD des positions
- **SecretRoutes**
  - Routes/secrets + réglages complets de rendu
- **Players Leaped**
  - `x/4 Players Leaped` sur les spots F7 Terms

### Misc
- **Command Aliases**
  - `/d`, `/dung`, `/ai`, `/pko`, `/pd`, `/pk`, `/pt`, `/lsb`, `/ld`, `/f1-7`, `/m1-7`
- **Custom Keybinds**
  - Wardrobe / Equipment / Trades / Garden / Pets
- **InvButtons**
  - Boutons inventaire + éditeur de position
- **ZguegAddons**
  - Chat hider, crypts/class notify, party commands `!boom !rng !gay !racist !py !gwer !size !911`

### Dev
- **Colors**
  - Couleur du GUI
- **Edit HUD**
  - Déplacement + scale des HUD elements
- **Debug**
  - `/xa title`, `/xa petrule`, `/xa ticlass`, `/xa secretroom`

## Commandes

- `/xa`
- `/xenaddons`
- `/invbuttons`

## Dépendances

- Fabric Loader
- Fabric API
- Java 21+
