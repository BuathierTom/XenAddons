# XenAddons 1.2.8

**Minecraft 1.21.10 (Fabric)**

## Added

- `Lava Remplacement` (lava visual replacement)
- `Compact Potion Message` (compact colored potion chat lines)
- `Cooldown Items` (SkyHanni-style cooldown overlays + mage CDR in dungeons)
- `Custom Hyperon Sound` (custom Wither Blade sound, with selector/volume/pitch + test button)

## Changes

- `Copy Chat`: `Alt/Option + right-click` copies formatted chat text
- `Spotify Overlay`: long titles are truncated with `...`
- `Item Price`: `[SHIFT show x..]` hides while Shift is held
- `Players Leaped` removed from active module list

## Fixes

- Custom Hyperon Sound now properly suppresses base hype sounds (explosion/teleport/cure/fizz) in replacement window
