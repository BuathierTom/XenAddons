# XenAddons 1.2.1

**Minecraft 1.21.10 (Fabric)**

## Fixes

- **Copy Chat** now selects the clicked line more reliably
  - Better matching between visible wrapped line and original message
  - More consistent clipboard output

- **Visual Words** matching improved for friend list messages
  - Better name boundaries
  - Better handling with color-formatted chat lines

- **SecretRoutes** line width consistency improved
  - Reduced segment-by-segment width variation
