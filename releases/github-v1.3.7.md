# XenAddons v1.3.7

Minecraft `26.1.2` • Fabric • Java `25+`

## Fixed

- **Peek Chat**
  - Fixed Peek Chat rendering on Minecraft `26.1.2`.
  - Improved scroll handling so mouse wheels and trackpads behave more reliably.

## Removed

- **Lava Replacement**
  - Removed the feature completely.
  - This avoids crashes with Sodium/Fabric fluid rendering when lava was replaced with water-like rendering.

- **Mask Reminder**
  - Removed the feature completely.
  - Removed its debug commands and settings.

## Changed

- **Docs / Release Metadata**
  - Updated version references to `1.3.7`.
  - Updated README compatibility to Minecraft `26.1.2` and Java `25+`.
