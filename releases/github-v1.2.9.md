# XenAddons v1.2.9

Minecraft `1.21.10` • Fabric

## Added

- **Dungeon**
  - `Better Party Finder`
    - Reworked Party Finder join/class system messages.
    - Detailed dungeon stats output for joining players.
    - Quick actions in chat (`kick`, `block`, `pv`) with direct command execution.
  - `Bat Death Alert`
    - Alerts when a bat is killed in dungeons.

- **Misc**
  - `Experimentation Table Solver`
    - Chronomatron solver support.
    - Ultrasequencer solver support.
    - Superpairs discovered-item visibility.
    - Superpairs XP overlay display on discovered items.

## Changed

- Added `/xa hud` command to open the mod HUD editor directly.
- Improved chat click handling stability for direct PF actions.
- Multiple PF stats formatting/tooltip improvements.

## Fixes

- Fixed chat click confirmation edge cases on PF action lines.
- Fixed several Experimentation Table rendering/solver timing issues.
- General stability fixes across new dungeon and misc modules.

## Documentation

- Bumped mod version to `1.2.9`.
- Updated `README.md`.
- Updated Modrinth long description (`releases/-description-modrinth.md`).
