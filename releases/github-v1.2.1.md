# XenAddons v1.2.1

Minecraft `1.21.10` • Fabric

## Fixed

- Improved **Copy Chat** line targeting in chat screen:
  - Better mapping between clicked visible line and full message
  - More reliable copy result on wrapped/scrolled chat lines
  - Keeps VisualWords-safe clipboard behavior (copies original message content)

- Improved **Visual Words** matching for friend list style lines:
  - Better boundary detection around names
  - Handles legacy color codes around names more safely
  - Better handling of concatenated status text patterns

- Improved **SecretRoutes** line rendering consistency:
  - Unified segment thickness behavior for route lines
  - Reduced visible thickness jumps between segments

## Changed

- Removed `!911` command from **ZguegAddons**
